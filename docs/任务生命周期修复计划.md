# 任务生命周期修复计划

范围：保持现有接口及用户改动，修复任务准入、CDK 回滚与浏览器清理。

1. 添加隔离回归测试：直接执行源码函数并注入依赖，不启动服务、不连接数据库、不付款。
2. server.js：同一 CDK 提交阶段互斥；并发名额提前预占；仅持锁请求可以回滚；manual 结果保持 CDK 锁。
3. index.js：finally 无条件关闭任务 context，与录像开关解耦。
4. browser-pool.js：健康检查前同步预占槽位，防止异步检查期间重复分配。
5. 执行新增回归、现有 npm test 与 node --check，记录验证边界。

本次不调整 UI、不部署、不操作真实支付或重置数据。跨服务实例的全局并发限制不在本次修复范围内。

## 实施与验证结果

已修改 `server.js`、`index.js`、`browser-pool.js`，新增 `test/task-lifecycle.test.js`。

- 同一 CDK 提交阶段互斥；在数据库校验期间预占服务进程并发名额，并在 finally 释放。
- 请求只有在取得 CDK 锁且尚未派发任务时才可因异常回滚。
- 本地 worker 返回 manual、成功或启动后抛出异常时保留 CDK，manual 加入终态集合。
- 录像关闭时仍关闭 context；最终清理额外兜底，保持池进程复用。
- 槽位健康检查前同步预占，重建槽位继承占用状态。

验证：2026-11-09，`npm test`：10 个测试文件、50 项测试全部通过，其中新增生命周期回归 8 项。`node --check server.js`、`node --check index.js`、`node --check browser-pool.js` 全部通过。

限制：测试使用注入依赖，不连接真实数据库或浏览器、不执行付款；未重启现有服务。未完成全项目支付审计、第三方供应商幂等核查、跨实例分布式并发控制或 Windows 强杀子进程后的浏览器回收验证。保留人工核对锁不等于已自动核对订单，需管理员核实后处理。
